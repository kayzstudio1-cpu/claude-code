# Jarvis Poster: Chrome extension

Post one video to **TikTok**, **Instagram** and **YouTube** from Chrome, using the accounts you're already logged in to. It's free, with no developer keys and no third-party service.

## Install (about one minute)

1. Download `jarvis-poster-extension.zip` and unzip it. You get a folder called `jarvis-extension`.
2. In Chrome, go to `chrome://extensions`.
3. Turn on **Developer mode** (top-right switch).
4. Click **Load unpacked** and choose the unzipped `jarvis-extension` folder.
5. Click the puzzle-piece icon in Chrome's toolbar and pin **Jarvis Poster**.

## Use it

1. Click the **J** icon. The Jarvis dashboard opens.
2. Drop in your video, then write the title, caption and hashtags.
3. Press **POST EVERYWHERE**. Jarvis opens TikTok, Instagram and YouTube Studio in new tabs.
   - If a site asks you to log in, log in normally. Jarvis waits up to 10 minutes and then carries on.
4. In each tab Jarvis attaches your video and fills in the caption. A **JARVIS** box in the corner says when it's ready.
5. Check each tab and press **Post** (TikTok), **Share** (Instagram) or **Publish** (YouTube; click Next through the steps and pick Public first).

If a site changes its layout and Jarvis gets stuck, the box says what it couldn't do. Click **Copy caption** in the box to paste the caption yourself.

## Notes

- Your video stays on your computer. Jarvis only puts it into each site's own upload form, the same as if you chose it yourself.
- Jarvis never presses Post for you, so you always check the post before it goes live.
- Instagram posts from the web need to be under about 15 minutes; vertical 9:16 works best everywhere.
