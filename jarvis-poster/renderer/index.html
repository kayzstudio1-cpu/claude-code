Platforms

Add a video and connect at least one account.

Each platform only allows posting through an app you register with them. Do this once per platform, paste the keys here, then press Connect. Keys are stored on this computer only.

YT

YouTube

  1. Open Google Cloud Console and enable YouTube Data API v3.
  2. Create an OAuth client ID of type Desktop app. Add yourself as a test user on the consent screen.
  3. Paste the Client ID and Client Secret below.
TT

TikTok

  1. Create an app at TikTok for Developers, add Login Kit and Content Posting API.
  2. Platform: Desktop. Redirect URI: http://localhost:53682/callback
  3. Scopes: user.info.basic, video.upload, video.publish. Paste the keys below.
IG

Instagram

  1. Your Instagram must be a Professional (Business or Creator) account.
  2. Create an app at Meta for Developers with the Instagram product and generate an access token with content-publish permission.
  3. Paste the token and your Instagram user ID below.
